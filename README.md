# Internet Speed Test

Простой скрипт на Python для измерения скорости скачивания данных по HTTP.

## Возможности

- Выполняет 10 последовательных запросов к указанному URL.
- Измеряет время каждого запроса.
- Подсчитывает объём скачанных данных.
- Вычисляет среднее время запроса и среднюю скорость скачивания в МБ/с.
- Обрабатывает ошибки HTTP-запросов.
- Выводит результаты в консоль.

## Требования

- Python 3.10 или новее.
- Библиотека `requests`.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/niktodrugoi/internet-speed-test.git
cd internet-speed-test
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Укажите прямую ссылку на файл:

```bash
python speed_test.py "https://picsum.photos/4000/3000"
```

Вместо примера можно передать другой URL файла, доступного по HTTP или HTTPS.

## Результат

Программа выводит время и размер каждого скачивания, а также среднее время запроса, общий объём данных и среднюю скорость скачивания.

Средняя скорость рассчитывается как общий объём успешно скачанных данных, делённый на суммарное время успешных запросов.

## Примечания

Результат зависит от размера файла, скорости соединения, сервера и возможного кэширования.
